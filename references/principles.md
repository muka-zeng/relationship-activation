# 深层原则与工作模式（Principles & Modes）

本文件记录关系激活的扩展原则与特殊工作模式。

## Context Broadcasting（朋友圈策略）

如果用户想通过朋友圈激活大量弱关系，**不要建议持续发布"销售内容"**。建议建立 **Context Broadcasting**——持续公开表达：

### 我最近在研究什么
### 我最近遇到什么问题
### 我观察到什么现象
### 我正在做什么实验
### 我从别人身上学到了什么
### 我最近发生了什么变化

目标：

> 给沉睡联系人一个重新认识用户的机会。

朋友圈不是直接销售渠道，它首先是 **Context Rebuilding System**——让别人重新知道："这个人现在在干什么？"

## Weak Relationship Principle（弱关系价值原则）

弱关系的价值不只在于成交。评估联系人时，应该优先寻找：

> 这个人连接着什么信息、经验和网络？

因此不仅考虑"他是否可能成为客户"，还考虑：

- 他是否拥有用户不知道的信息
- 他是否处于不同的信息网络
- 他是否了解目标人群
- 他是否正在经历用户正在研究的问题
- 他是否可能提供新的连接

**但禁止把人简单评分成"资源价值"。**

## Batch Mode（批量模式）

如果用户提供多个人：**不要立即给每个人生成消息**。首先建立：

```text
联系人
↓
关系状态
↓
激活机会
↓
优先级
```

按以下优先级排序：

- **Tier A**：已有真实连接 + 当前存在自然话题。
- **Tier B**：过去有关系 + 用户近期发生变化，可以重新建立语境。
- **Tier C**：过去有关系，但当前缺乏自然连接点。
- **Tier D**：纯粹为了商业目的而联系，没有真实关系基础。

优先处理 Tier A。**不要为了数量而批量触达 Tier C/D。**

## Self-Reflection Mode（自我反思模式）

如果用户说"我不知道该联系谁"，不要立即让用户列出所有联系人。先问：

1. 你最近正在做什么？
2. 你最近正在研究什么问题？
3. 你最近希望认识什么类型的人？
4. 你过去认识过哪些可能与这个问题相关的人？

然后从用户的记忆中反向寻找联系人。原则：

> **先找共同问题，再找联系人。**

而不是：先翻通讯录，再想怎么卖。

## Trigger → Mode Mapping（触发到模式映射）

| 触发类型 | 进入模式 | 说明 |
|---|---|---|
| 显式关系激活 / 重连 | Relationship Activation Workflow | 完整 8 步流程（见 SKILL.md） |
| 弱关系描述（认识不熟等） | Relationship State Diagnosis | 先诊断状态，不自动生成消息 |
| 转行 / 创业 / 离职 / 找工作 | Network Re-activation Mode | 用新身份作为重新连接的自然理由 |
| 朋友圈内容困惑 | Context Broadcasting Mode | 先判断要建立什么新上下文，再生成内容 |
| 用户贴出对方回复 | Relationship Response Analysis | 按 Signal A–D 决定推进/暂停/停止 |
| 用户贴出待发草稿 | Relationship Friction Audit | 先查真实性/摩擦/关系匹配，再改文字 |
| 同时满足多个 | 按 Trigger Priority 取最高级 | 见 triggers.md |

## Final Principle

> 影响力来自理解和信任，而不是操纵。
