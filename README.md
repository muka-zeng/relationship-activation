# relationship-activation 关系激活 Skill

帮助用户从已有的**弱关系、沉睡联系人和低频关系**中，发现真实的重新连接机会，并设计一个**低摩擦、真诚、符合当前关系状态的下一步互动**。

本 Skill 不以"成交"为第一目标，核心目标是：**让一段已经沉睡的关系，重新产生一次真实的交集。**

## 核心原则

> **关系优先于交易（Relationship Before Transaction）**

- 不先把联系人看成潜在客户、合作伙伴、转介绍资源、KOL 或流量入口，而是先看成一个具体的人。
- 第一问题不是"这个人能给我带来什么？"，而是"我们之间现在还剩下什么真实连接？"

## 适用场景

- 激活朋友圈 / 微信好友
- 职业转型、转行、创业、离职后重建人脉
- 重新联系老朋友、前同事、培训或活动认识的人
- 寻找第一批客户、访谈对象、合作伙伴、行业信息
- 找工作或职业机会
- 从弱关系中自然发现商业机会
- 分析对方的回复，决定下一步怎么走

## 主要特性

- **8 条关系公理**：从对方的世界出发、保护心理安全、真实兴趣、记住这个人、给对方表达空间、跟随对方兴趣、让对方思考、关系先于正确。
- **关系状态机 S0–S6**：从沉睡 → 重新连接机会 → 第一次互动 → 互惠对话 → 共同语境 → 活跃关系 → 机会，每次互动最多推进一级。
- **激活质量公式**：`Activation Quality ≈ Relevance × Authenticity × Reciprocity ÷ Friction`
- **8 步工作流**：澄清目标 → 理解对方 → 关系诊断 → 寻找激活机会 → 选择互动类型 → 生成消息 → 模拟回应 → 回应导航。
- **回应信号分析**：热回应推进一级 / 中性回应暂停 / 冷淡或沉默停止。
- **完整触发目录**：显式触发、弱关系触发、重连触发、商业触发、职业触发、朋友圈内容触发、回复触发、草稿审查触发。
- **反操纵规则**：禁止虚假赞美、假装关心、伪装成请教进行销售等；影响力来自理解和信任，而不是操纵。

## 工作流概览

```text
用户想激活关系
        ↓
为什么联系？
        ↓
是否存在真实目标？
   ┌────┴────┐
   否        是
   ↓         ↓
重新澄清    找联系人
             ↓
       是否存在真实连接？
       ┌─────┴─────┐
       否          是
       ↓           ↓
   不建议联系    找连接点
                    ↓
             是否自然？
             ┌────┴────┐
             否        是
             ↓         ↓
          暂缓      选择行动
                       ↓
                  最小有效动作
                       ↓
                    发起互动
                       ↓
                 读取对方回应
                       ↓
          ┌────────────┼────────────┐
          ↓            ↓            ↓
        热回应       中性回应      冷淡/沉默
          ↓            ↓            ↓
       推进一级        暂停          停止
          ↓
       更新关系状态
```

## 安装与使用

1. 将本仓库克隆或下载到 AI Agent 的 skills 目录（如 `workspace/.user_skills/`）：

```bash
git clone https://github.com/muka-zeng/relationship-activation.git
# 将 relationship-activation 文件夹放入 skills 根目录
```

2. 在对话中描述你想激活的关系即可触发，例如：
   - "帮我激活一下这个人，三年没联系了"
   - "怎么重新联系一个老朋友？"
   - "帮我把朋友圈盘活"
   - "我想重新建立人脉"

## 原则声明

本 Skill 基于 Dale Carnegie《How to Win Friends and Influence People》的核心原则抽象，并明确禁止将其解释为操纵技巧。

> **影响力来自理解和信任，而不是操纵。**
